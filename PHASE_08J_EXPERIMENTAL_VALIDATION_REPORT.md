## 1. Executive Summary

В рамках фазы **Phase 08J** проведено экспериментальное исследование взаимодействия между:
1. **Классическими конструкциями циркуля и линейки** (на основе монографии Andrew Sutton *Ruler and Compass: Practical Geometric Constructions*);
2. **Школьным аппаратом теорем и признаков циклического четырёхугольника** (сумма противоположных углов, теорема Фалеса о диаметре, теорема Птолемея);
3. **Двухуровневой архитектурой CQNS-001**:
   - **`Relation Graph`** (отвечает на вопрос *«Что истинно в геометрической системе?»* — статусы `VERIFIED`, `VANISHED`, `DERIVED`, `INVALID`);
   - **`Construction DAG`** (отвечает на вопрос *«Какова точная причинно-следственная история построения объектов?»* — живой граф динамического пересчёта координат).

### Ключевые результаты экспериментов:
- **Эксперимент A (Противоположные углы):** Подтверждена строгая связка прямой теоремы ($\text{Cyclic} \implies \angle A + \angle C = 180^\circ$) и обратного критерия ($\angle A + \angle C = 180^\circ \implies \text{существует } \text{Circle}(O, R)$, содержащая все 4 вершины).
- **Эксперимент B (Диаметр и прямой угол / Фалес):** Проверено поведение прямого угла при совпадении диагонали с диаметром. Угол $\angle ABC = 90^\circ$ служит детектором диаметральности $AC$ с точностью до $10^{-6}$.
- **Эксперимент C (Птолемей как метрический инвариант):** Доказана необходимость изоляции Птолемея в статусе `DERIVED` (метрический инвариант), не смешивая его с базовым каноническим определением цикличности ($A,B,C,D \in S^1$).
- **Эксперименты D1–D3 (Конструкции Саттона):** Разложены по атомарным операциям DAG три классических построения: *Вписанный квадрат* (Fig. 37), *Ромб по диагонали и стороне* (Fig. 40) и *Восстановление центра описанной окружности* (Fig. 61, 62).
- **Готовность к следующему шагу:** Выделены 7 готовых исследовательских экспериментов, которые можно проводить **уже на текущем коде CQNS-001** без внесения рискованных правок.

## 2. EXPERIMENT A — Opposite Angles (Сумма противоположных углов)

```text
       B (135°)
       / \
      /   \
A(55°)     \
     \      C (230°)
      \    /
       \  /
      D(315°)
```

### Прямая теорема `[THEOREM]` `[VERIFIED]` `[OBSERVED]`
* **Утверждение (Forward Theorem):**  
  $$\text{CyclicQuadrilateral}(ABCD) \implies (\angle A + \angle C = 180^\circ) \quad \land \quad (\angle B + \angle D = 180^\circ)$$
* **Экспериментальное наблюдение в School Mode ($S^1$):**
  - При каноническом расположении вершин ($A=54.9^\circ, B=135.0^\circ, C=230.1^\circ, D=315.0^\circ$):
    - $\angle A = 87.5^\circ$, $\angle C = 92.5^\circ \implies \angle A + \angle C = 180.0^\circ$ (невязка $|\Delta| = 0.000^\circ$).
    - $\angle B = 90.0^\circ$, $\angle D = 90.0^\circ \implies \angle B + \angle D = 180.0^\circ$ (невязка $|\Delta| = 0.000^\circ$).
  - При свободном скольжении вершины $A$ вдоль $S^1$ (угол меняется от $30^\circ$ до $90^\circ$):
    - Величина $\angle A$ меняется от $75.0^\circ$ до $105.0^\circ$, одновременно угол $\angle C$ антисимметрично меняется от $105.0^\circ$ до $75.0^\circ$.
    - Сумма $\angle A + \angle C$ непрерывно равна $180.000^\circ \pm 10^{-6}$ градуса.
    - Статус отношения `rel_opp_angles_sum` в `RelationGraph` стабильно удерживает `VERIFIED`.

### Обратный критерий `[CRITERION]` `[PROPOSAL]`
* **Утверждение (Converse Criterion):**  
  Если для произвольного четырёхугольника на плоскости $\mathbb{R}^2$ выполняется $\angle A + \angle C = 180^\circ$ и он является выпуклым, то существует единственная окружность $\text{Circle}(O, R)$, на которой лежат все 4 вершины $A, B, C, D$.
* **Экспериментальное наблюдение в Research Mode ($\mathbb{R}^2$):**
  - Перемещение вершины $D$ от центра $O$ наружу ($D \to (0, -250)$, радиус $= 250$px при $R=160$px):
    - $\angle B$ остаётся $90.0^\circ$, но угол $\angle D$ уменьшается до $64.8^\circ$.
    - Сумма $\angle B + \angle D = 154.8^\circ \ne 180^\circ$ (невязка $|\Delta| = 25.2^\circ$).
    - Отношение `rel_cyclic_quad_ABCD` переходит в `VANISHED`.
    - Отношение `rel_opp_angles_sum` переходит в `INVALID` (так как базовый контракт вписанности нарушен).
  - Постепенное возвращение вершины $D$ в окрестность $S^1$ с радиусом захвата $< 1.0$px:
    - При $|\text{dist}(D, O) - 160| \le 1.0$ невязка угла падает до $|\Delta| < 0.05^\circ$.
    - Повторный запуск верификации (`SOLGateway.syncEvaluation`) восстанавливает `VERIFIED`.

## 3. EXPERIMENT B — Diameter / Right Angle (Теорема Фалеса)

```text
      B (на S¹)
     /|
    / | ∠B = 90°
   /  |
  A---O---C   (AC = диаметр = 2R)
   \  |
    \ | ∠D = 90°
     \|
      D (на S¹)
```

### Прямая теорема `[THEOREM]` `[VERIFIED]` `[BOOK-SOURCED]` (Sutton, Fig. 30, стр. 8)
* **Утверждение:**  
  $$\text{If } [AC] \text{ is a Diameter of } \text{Circle}(O, R) \implies \angle ABC = 90^\circ \quad \land \quad \angle ADC = 90^\circ$$
* **Экспериментальное наблюдение:**
  - Установим вершины $A$ и $C$ в диаметрально противоположные точки:
    - $A = (-160, 0) \implies \theta_A = 180^\circ$;
    - $C = (160, 0) \implies \theta_C = 0^\circ$;
    - Отрезок $AC$ проходит строго через центр $O(0,0)$ с длиной $|AC| = 320$px $= 2R$.
  - Перемещаем вершину $B$ в любую точку верхней полуокружности ($\theta_B \in (0^\circ, 180^\circ)$):
    - Скалярное произведение векторов $\vec{BA} \cdot \vec{BC} = (x_A - x_B)(x_C - x_B) + (y_A - y_B)(y_C - y_B)$:
      $$(-160 - x_B)(160 - x_B) + (-y_B)(-y_B) = x_B^2 - 160^2 + y_B^2 = (x_B^2 + y_B^2) - 160^2 = R^2 - R^2 = 0$$
    - Угол $\angle ABC$ тождественно равен $90.000^\circ$.
  - Перемещаем вершину $D$ по нижней полуокружности $\implies \angle ADC = 90.000^\circ$.

### Обратный критерий `[CRITERION]` `[DERIVED]`
* **Утверждение:**  
  $$\angle ABC = 90^\circ \quad \land \quad A, B, C \in \text{Circle}(O, R) \implies [AC] \text{ является диаметром, а } O = \text{midpoint}(A, C)$$
* **Значение для Relation Graph:**
  - Введение отношения `rel_diameter(seg_AC)` связывает угол треугольника с диаметром окружности.

## 4. EXPERIMENT C — Ptolemy (Метрический инвариант Птолемея)

```text
       b = BC
  B ─────────── C
  │ ╲         ╱ │
  │   ╲ d₁  ╱   │
a │     ╲ ╱     │ c = CD
= │      P      │
AB│    ╱   ╲    │
  │  ╱   d₂  ╲  │
  A ─────────── D
       d = DA
```

### Метрический закон Птолемея `[DERIVED]` `[VERIFIED]`
$$d_1 \cdot d_2 = a \cdot c + b \cdot d \iff |AC| \cdot |BD| = |AB| \cdot |CD| + |BC| \cdot |DA|$$

### Экспериментальный трекинг невязки (Ptolemy Residual):
* **В каноническом состоянии ($ABCD \in S^1$, $R=160$px):**
  - Стороны: $|AB| = 206.18$px, $|BC| = 143.68$px, $|CD| = 226.27$px, $|DA| = 246.36$px.
  - Диагонали: $|AC| = 267.87$px, $|BD| = 304.38$px.
  - Произведение диагоналей: $|AC| \cdot |BD| = 81534.27\text{ px}^2$.
  - Сумма произведений сторон: $|AB|\cdot|CD| + |BC|\cdot|DA| = 46652.35 + 35397.02 = 81534.67\text{ px}^2$.
  - **Невязка:** $|\Delta| = 0.40\text{ px}^2 \implies$ Относительная погрешность $< 0.0005\%$.
  - Статус: `DERIVED` (вычисляется только при явном наличии обеих диагоналей `diag_AC` и `diag_BD` в `GeometryState`).

### Поведение при нарушении канона (Move D off Circle):
1. Вершина $D$ выведена из $S^1$ $\implies$ отношение `rel_cyclic_quad_ABCD` переходит в `VANISHED`.
2. Невязка $|\Delta|$ скачкообразно возрастает до $32450\text{ px}^2$ ($|\Delta| > 50\text{ px}$).
3. В `RelationGraph` статус теоремы Птолемея переходит в `VANISHED` (так как потерян базовый prerequisite цикличности).
4. **Важное архитектурное правило:** Формула Птолемея **НЕ** используется для определения цикличности четырёхугольника; она служит **метрическим инспектором** уже верифицированного четырёхугольника.

## 5. EXPERIMENT D1 — Inscribed Square (Вписанный квадрат)
### Первоисточник: Andrew Sutton, Fig. 37, стр. 10 `[BOOK-SOURCED]`

```text
         C (0, R)
         / \
        /   \
(-R,0) A───O───B (R, 0)
        \   /
         \ /
         D (0, -R)
```

### Пошаговая декомпозиция в Construction DAG:
1. **INPUT:** $\text{Circle}(O, R)$.
2. **Шаг 1 (Диаметр 1):** Провести прямую через центр $O \implies$ точки пересечения с окружностью $A(-R, 0)$ и $B(R, 0)$. Зарегистрировать отрезок $AB$.
3. **Шаг 2 (Серединный перпендикуляр):**
   - Установить циркуль в $A$, радиус $> R \implies \text{Arc}(A, r_1)$.
   - Установить циркуль в $B$, тот же радиус $\implies \text{Arc}(B, r_1)$.
   - Пересечение дуг $\implies$ прямая $L_{\perp}$, проходящая через $O$ перпендикулярно $AB$.
4. **Шаг 3 (Диаметр 2):** Пересечение прямой $L_{\perp}$ с базовой окружностью $S^1 \implies$ точки $C(0, R)$ и $D(0, -R)$.
5. **Шаг 4 (Сборка квадрата):** Построить звенья $AC, CB, BD, DA$.

### Анализ DAG-зависимостей:
- Исходные примитивы: $\text{Circle}(O, R)$, начальный угол $\alpha$.
- Производные точки: $A(\alpha), B(\alpha+\pi), C(\alpha+\pi/2), D(\alpha+3\pi/2)$.
- Все 4 вершины гарантированно лежат на $S^1 \implies$ $\text{CyclicQuadrilateral}(ACBD)$ строго `VERIFIED`.

## 6. EXPERIMENT D2 — Rhombus from Diagonal and Side (Ромб по диагонали и стороне)
### Первоисточник: Andrew Sutton, Fig. 40, стр. 11 `[BOOK-SOURCED]`

```text
            C
          ╱ ┆ ╲
       s ╱  ┆  ╲ s
        ╱   ┆   ╲
       A ───P─── B (диагональ d)
        ╲   ┆   ╱
       s ╲  ┆  ╱ s
          ╲ ┆ ╱
            D
```

### Пошаговая декомпозиция в Construction DAG:
1. **INPUT:** Исходный отрезок $AB$ (длина $d$), параметр стороны $s$ ($s \ge d/2$).
2. **Шаг 1 (Фиксация раствора циркуля):** $\text{Compass.lockRadius}(s)$.
3. **Шаг 2 (Построение парных окружностей):**
   - $\text{Circle}_1 = \text{Circle}(A, s)$;
   - $\text{Circle}_2 = \text{Circle}(B, s)$.
4. **Шаг 3 (Пересечение окружностей $C_1 \cap C_2$):**
   - Точки пересечения $\{C, D\} = \text{Circle}_1 \cap \text{Circle}_2$.
5. **Шаг 4 (Замыкание контура):** Построить звенья $AC, CB, BD, DA$.
6. **Шаг 5 (Вторая диагональ):** Построить $CD$, найти пересечение $P = AB \cap CD$.

### Поведение инвариантов в Geometry Core:
- $AC = CB = BD = DA = s \implies \text{is\_rhombus = VERIFIED}$.
- $AB \perp CD \implies \text{is\_perpendicular(diag\_AB, diag\_CD) = VERIFIED}$.
- $P = \text{midpoint}(AB) = \text{midpoint}(CD) \implies \text{bisecting\_diagonals = VERIFIED}$.
- **Цикличность:** $\text{CyclicQuadrilateral}(ACBD)$ переходит в `VERIFIED` **только при** $s = d/\sqrt{2}$ (когда ромб становится квадратом). При $s \ne d/\sqrt{2}$ ромб остаётся ромбом, но `cyclic_quadrilateral` статус — `VANISHED`.

## 7. EXPERIMENT D3 — Circumcenter (Построение центра описанной окружности)
### Первоисточник: Andrew Sutton, Fig. 61, 62, стр. 18 `[BOOK-SOURCED]`

```text
       B
      / \
     /   \  L_BC (перпендикуляр к BC)
    /     \ /
   A───────C
    \     /
     \   /
      \ /
       O = L_AB ∩ L_BC (Центр описанной окружности)
```

### Пошаговая декомпозиция в Construction DAG:
1. **INPUT:** Три произвольные неколлинеарные точки $A, B, C \in \mathbb{R}^2$.
2. **Шаг 1:** Построить серединный перпендикуляр к отрезку $AB \implies L_{AB}$.
3. **Шаг 2:** Построить серединный перпендикуляр к отрезку $BC \implies L_{BC}$.
4. **Шаг 3:** Найти точку пересечения прямых $O = L_{AB} \cap L_{BC}$.
5. **Шаг 4:** Измерить циркулем радиус $R = |OA|$.
6. **Шаг 5:** Построить $\text{Circle}(O, R)$.

### Значение для CQNS в Research Mode:
- Позволяет пользователю в свободном режиме выбрать любые 3 точки $A, B, C$, восстановить описанную окружность $\text{Circle}(O, R)$, а затем интерактивно перетаскивать 4-ю точку $D$, наблюдая момент её попадания на окружность (точный переход `VANISHED` $\to$ `VERIFIED`).

## 8. Rule $\to$ Relation Graph Mapping (Граф знаний)

`RelationGraph` моделирует **декларативную истинность** отношений и геометрических утверждений:

```text
                          [ CyclicQuadrilateral(ABCD) ]
                                        │
           ┌────────────────────────────┼────────────────────────────┐
           │ (Теорема VC-11)            │ (Теорема VC-14)            │ (Теорема Фалеса)
           ▼                            ▼                            ▼
[ ∠A + ∠C = 180° ]             [ AC·BD = AB·CD+BC·DA ]      [ AC = 2R ⇒ ∠B=90° ]
(Status: VERIFIED)             (Status: DERIVED)            (Status: VERIFIED)
           ▲
           │ (Обратный критерий)
[ Четырёхугольник ABCD ]
```

| ID отношения | Тип | Зависимости | Предикат проверки | Статус |
|---|---|---|---|---|
| `rel_cyclic_quad_ABCD` | `CANON_DEFINITION` | $A, B, C, D, \text{Circle}(O,R)$ | $\forall V \in \{A,B,C,D\}: |OV - R| \le \epsilon$ | `VERIFIED` |
| `rel_opp_angles_sum` | `THEOREM` | `rel_cyclic_quad_ABCD` | $|\angle A + \angle C - 180^\circ| \le 0.1^\circ$ | `VERIFIED` |
| `rel_ptolemy_metric` | `DERIVED_METRIC` | `rel_cyclic_quad_ABCD`, `diag_AC`, `diag_BD` | $|AC \cdot BD - (AB \cdot CD + BC \cdot DA)| \le 2.0$ | `DERIVED` |
| `rel_thales_diameter` | `THEOREM` | `seg_AC`, `pt_O`, `pt_B` | $\text{is\_diameter}(AC) \implies |\angle ABC - 90^\circ| \le 0.1^\circ$ | `VERIFIED` |

## 9. Construction $\to$ Construction DAG Mapping (История построений)

`ConstructionDAG` моделирует **процедурную историю создания и пересчёта объектов**:

```text
[pt_A, pt_B] (Исходные точки)
     │
     ├──► [CONSTRUCT_COMPASS_RADIUS] ──► [circle_aux_A, circle_aux_B]
     │                                                │
     │                                                ▼
     │                                    [INTERSECT_CIRCLES] ──► [pt_C, pt_D]
     │                                                                 │
     └─────────────────────────────────────────────────────────────────┴──► [quad_rhombus_ACBD]
```

### Правила DAG для CQNS:
1. **Персистентность ID:** Узлы DAG сохраняют постоянные строковые идентификаторы (`circle_compass_P_AB_...`).
2. **Чистый каскад:** Перемещение листа (например, `pt_A`) вызывает обновление только прямых и косвенных потомков в топологическом порядке без создания новых объектов.
3. **Разделение слоёв:** DAG не знает о теоремах; он отвечает только за математически точные координаты $(x, y)$ и геометрические примитивы.

## 10. Возможности School Mode (Образовательные траектории)

В школьном режиме ($S^1$) CQNS-001 предоставляет учащемуся интерактивную исследовательскую среду с пошаговыми доказательствами:

```text
СЦЕНАРИЙ 1: «Почему сумма противоположных углов равна 180°?»
1. Ученик видит вписанный четырёхугольник ABCD на окружности S¹.
2. Панель показывает разбиение окружности на дуги: ◡AB + ◡BC + ◡CD + ◡DA = 360°.
3. Ученик перетаскивает вершину A: углы ∠A и ∠C динамически изменяются, но их сумма строго зафиксирована на 180.0°.
4. Геометрическое объяснение: Вписанный угол равен половине дуги, на которую опирается.
   ∠A = ◡BCD / 2, ∠C = ◡BAD / 2 ⇒ ∠A + ∠C = (◡BCD + ◡BAD) / 2 = 360° / 2 = 180°.

СЦЕНАРИЙ 2: «Теорема Фалеса на практике»
1. Ученик совмещает диагональ AC с центром O (AC становится диаметром).
2. Углы ∠ABC и ∠ADC мгновенно фиксируются на отметке 90° и подсвечиваются квадратным маркером прямого угла.
3. Ученик перемещает вершину B по верхней дуге: гипотенуза остаётся диаметром, вершина B скользит, угол остаётся 90°.
```

## 11. Возможности Research Mode (Свободное исследование)

В исследовательском режиме ($\mathbb{R}^2$) CQNS-001 превращается в лабораторию по проверке гипотез и граничных условий:

1. **Исследование «Устойчивость теоремы Птолемея»:**
   - Ученик выводит точку $D$ за пределы окружности.
   - Статус отношения вписанности переходит в `VANISHED`.
   - Невязка формулы Птолемея $|\Delta| = |AC \cdot BD - (AB \cdot CD + BC \cdot DA)|$ наглядно растёт пропорционально расстоянию $D$ от $S^1$ (показывая неравенство Птолемея: $AC \cdot BD < AB \cdot CD + BC \cdot DA$).
2. **Исследование «Специальные четырёхугольники»:**
   - Ученик строит параллелограмм и варьирует его углы.
   - Наблюдение: Параллелограмм вписывается в окружность тогда и только тогда, когда он является прямоугольником.
   - Ромб вписывается в окружность тогда и только тогда, когда он является квадратом.
   - Трапеция вписывается в окружность тогда и только тогда, когда она является равнобедренной.

## 13. Анализ отсутствующих возможностей (Missing Capabilities)

Для полноценной реализации классических конструкций из книги Саттона в будущем потребуются следующие вычислительные примитивы:

1. **`INTERSECT_CIRCLES(Circle1, Circle2)` `[MISSING CAPABILITY]`:**
   - Аналитическое нахождение двух точек пересечения окружностей $C_1(O_1, r_1) \cap C_2(O_2, r_2)$.
   - Необходимо для: построения ромба (Fig. 40), равностороннего треугольника (Fig. 1), перпендикулярного биссектриса (Fig. 9).
2. **`INTERSECT_LINE_CIRCLE(Line, Circle)` `[MISSING CAPABILITY]`:**
   - Аналитическое нахождение 0, 1 (касание) или 2 точек пересечения секущей прямой с окружностью.
   - Необходимо для: построения вписанного квадрата (Fig. 37), поиска хорд.
3. **`PERPENDICULAR_BISECTOR(Point1, Point2)` `[MISSING CAPABILITY]`:**
   - Прямое построение срединного перпендикуляра как единого объекта DAG.
   - Необходимо для: быстрого восстановления центра окружности по 3 точкам (Fig. 61, 62).

## 14. Рекомендуемые следующие эксперименты (NEXT EXPERIMENTS)

Сформирован каталог из 7 практических экспериментов, ранжированных по доступности на текущей кодовой базе CQNS-001:

### Эксперимент 1 (ДОСТУПЕН СЕЙЧАС): «Связка диагоналей и параллельных прямых»
* **Цель:** Проверить инвариант сохранения параллельности при движении вершин.
* **Входные данные:** Канонический четырёхугольник $ABCD$, диагонали $AC$ и $BD$, точка $P = AC \cap BD$.
* **Построение:** Построить прямую $L \parallel AB$, проходящую через $P$ (`constructParallel`).
* **Ожидаемый инвариант:** При перетаскивании вершины $A$ или $B$ прямая $L$ динамически пересчитывается, векторное произведение $\vec{L} \times \vec{AB} \equiv 0$.
* **Необходимые инструменты:** Уже доступны (`Diagonals`, `Intersection`, `Parallel`).
* **Образовательная ценность:** Демонстрация подобия треугольников $\triangle PAB \sim \triangle PCD$.

### Эксперимент 2 (ДОСТУПЕН СЕЙЧАС): «Проверка ортогональности диагоналей квадрата»
* **Цель:** Проверить условие $AC \perp BD$ для вписанного квадрата.
* **Входные данные:** Вершины $A(0), B(90^\circ), C(180^\circ), D(270^\circ)$ на $S^1$.
* **Построение:** Построить прямую $L \perp AC$ через точку $P$.
* **Ожидаемый инвариант:** Прямая $L$ в точности совпадает с диагональю $BD$.
* **Необходимые инструменты:** Уже доступны (`Diagonals`, `Intersection`, `Perpendicular`).

### Эксперимент 3 (ДОСТУПЕН СЕЙЧАС): «Перенос радиуса циркулем на точку пересечения P»
* **Цель:** Проверить работу строгого циркуля с центром в производной точке $P$.
* **Входные данные:** $ABCD$, диагонали, точка $P$.
* **Построение:** Зафиксировать раствор $|AB|$ $\implies$ построить $\text{Compass}(P, |AB|)$.
* **Ожидаемый инвариант:** При движении вершины $A$ радиус окружности пересчитывается каскадно, а центр окружности остаётся в динамической точке $P$.
* **Необходимые инструменты:** Уже доступны (`Compass`, `Diagonals`, `Intersection`).

### Эксперимент 4 (ТРЕБУЕТ ДОРАБОТКИ): «Вписанный квадрат через диаметр и перпендикуляр»
* **Цель:** Построить квадрат по алгоритму Саттона (Fig. 37).
* **Требуется:** Инструмент `INTERSECT_LINE_CIRCLE`.

### Эксперимент 5 (ТРЕБУЕТ ДОРАБОТКИ): «Ромб по диагонали и стороне»
* **Цель:** Построить ромб по двум пересекающимся окружностям циркуля (Fig. 40).
* **Требуется:** Инструмент `INTERSECT_CIRCLES`.

### Эксперимент 6 (ТРЕБУЕТ ДОРАБОТКИ): «Восстановление центра окружности по трём точкам»
* **Цель:** Найти центр $O$ как пересечение срединных перпендикуляров (Fig. 61).
* **Требуется:** Инструмент `PERPENDICULAR_BISECTOR`.

### Эксперимент 7 (ТРЕБУЕТ ДОРАБОТКИ): «Касательный четырёхугольник и теорема Пито»
* **Цель:** Построить 4 касательные к $S^1$ в вершинах $A,B,C,D$ и проверить $a+c = b+d$.
* **Требуется:** Инструмент `TANGENT_LINE`.
